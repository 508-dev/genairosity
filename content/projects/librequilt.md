# librequilt

Quilters who design their own quilts draw blocks, lay them out, try fabrics, and print a chart of how much fabric to buy and how to cut it. This project is researching a free tool for that loop.

## Scope

Proposed first scope: a block editor, a small library of traditional blocks, quilt layout, colouring with solids or the quilter's own fabric photos, and a printable yardage and cutting chart in an open file format. It does not open the incumbent's project files, export to quilting machines, or ship manufacturers' fabric images. Nothing here is an approved specification; the charter in the repository is a draft for the maintainer to edit.

## Current limitations

The project is in research. There is no application code and no approved specification. The platform is undecided: the research recommends browser-first, because the audience uses Windows, macOS and iPads. No one from the intended community has been interviewed yet.
