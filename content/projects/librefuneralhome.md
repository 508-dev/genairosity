# librefuneralhome

Independent funeral homes carry each case from the first call to the final bill, and must give families price documents in the form the United States Funeral Rule requires. This project is researching a case tracker built around generating those documents correctly.

## Scope

Proposed first scope: one location; case records, the home's price lists, the General Price List and itemised statement, an arrangement checklist and a simple invoice. It does not file death certificates, handle pre-need trust accounting, or process payments. Nothing here is an approved specification; the charter in the repository is a draft for the maintainer to edit.

## Current limitations

The project is in research. There is no application code and no approved specification. The platform is undecided: the research reads these users as working on Windows desktops and in the browser. No one from the intended community has been interviewed yet.
