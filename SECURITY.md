# Security reporting

Report sensitive vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/508-dev/genairosity/security/advisories/new).
Do not put secrets, exploit details, or proprietary material in public issues.
If private reporting is unavailable, open a minimal issue asking a maintainer for
a private reporting channel, without disclosing the sensitive information.

This hub is a static site. It stores no visitor accounts, model credentials, or
application database. Keep local credentials in your own environment and never
commit them. Treat research links, issue text, generated code, and dependencies
as untrusted inputs until reviewed. A human remains accountable for their tools.

Each registered project must document its own security and release expectations
before distributing usable software. No warranty is provided.
