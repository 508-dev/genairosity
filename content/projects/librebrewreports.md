# librebrewreports

Small United States breweries must keep production, removal and inventory records and file a federal report of operations and an excise return. This project is researching a tool that keeps those records and fills the forms for a person to review and submit.

## Scope

Proposed first scope: beer only; a local ledger, the Brewer's Report of Operations computed from it, and an audit trail. It does not file electronically, pay tax, or cover state reports. Nothing here is an approved specification; the charter in the repository is a draft for the maintainer to edit.

## Current limitations

The project is in research. There is no application code and no approved specification. The platform is undecided: the research reads these users as working on Windows and Mac laptops. No one from the intended community has been interviewed yet.
